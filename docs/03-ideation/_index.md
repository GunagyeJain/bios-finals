# 03-ideation

How it works: each member writes ideas only in their own folder (no conflicts), then everything
is merged in `synthesis/`. Full flow: `../../CONTRIBUTING.md` §4.

- `idea-template.md`: copy this for each idea (`<your-folder>/idea-<short-name>.md`)
- `scoring.md`: how ideas are scored (criteria + weights)
- `shefali/`: Shefali's ideas and notes
- `bhavyam/`: Bhavyam's ideas and notes
- `abhijay/`: Abhijay's ideas and notes
- `gunagye/`: Gunagye's ideas and notes
- `synthesis/`: merged shortlist, scores, final pick
